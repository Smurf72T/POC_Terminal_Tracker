# План исправления ошибок при открытии документов

## Проблема
При открытии документов возникает ошибка:
```
Не удалось проверить структуру БД
Ошибка безымянный подготовленный оператор не существует (26000)
QPSql Unable to send query
```

## Корневая причина
В файле `src/ui/dialogs/rentalform.cpp` функция `ensureCommentColumn()` использует PostgreSQL блок `DO $$ ... END $$` с подготовленными операторами:

```cpp
query.prepare(
    "DO $ BEGIN "
    "  IF NOT EXISTS (SELECT 1 FROM information_schema.columns "
    "                 WHERE table_name='tblrentaldetails' AND column_name='comment') THEN "
    "    ALTER TABLE tblrentaldetails ADD COLUMN comment TEXT; "
    "  END IF; "
    "END $"
);
```

PostgreSQL не поддерживает использование подготовленных операторов (PREPARE/EXECUTE) с анонимными блоками `DO $$`. Это вызывает ошибку "prepared statement does not exist".

## Решение

### 1. Исправить `rentalform.cpp` - заменить `DO $$` на прямые запросы

**Файл:** `src/ui/dialogs/rentalform.cpp`

Заменить функцию `ensureCommentColumn()` на:
```cpp
void RentalForm::ensureCommentColumn()
{
    QSqlQuery query(DatabaseManager::instance().getDatabase());
    // Проверяем существование колонки
    query.exec("SELECT 1 FROM information_schema.columns "
               "WHERE table_name='tblrentaldetails' AND column_name='comment'");
    
    if (!query.next()) {
        // Колонки нет, добавляем её
        query.exec("ALTER TABLE tblrentaldetails ADD COLUMN comment TEXT");
    }
    
    if (query.lastError().isValid() && !query.lastError().text().isEmpty()) {
        QMessageBox::critical(this, "Ошибка БД",
            "Не удалось проверить структуру БД: " + query.lastError().text());
    }
}
```

### 2. Проверить наличие функции `generate_doc_number` в БД

**Файл:** `src/database/databasemanager.cpp` (строка 125)

Функция вызывает `SELECT generate_doc_number(:doc_type)`, но:
- Эта функция не вызывается в коде (неиспользуемый код)
- Может не существовать в БД

**Действия:**
1. Проверить, существует ли функция в БД
2. Если не существует и не используется - удалить из `databasemanager.h` и `databasemanager.cpp`
3. Или создать SQL-скрипт для её создания

### 3. Проверить другие формы на аналогичные проблемы

Проверить все файлы в `src/ui/dialogs/` на использование:
- `query.prepare()` с SQL блоками `DO $$`
- `query.prepare()` с DDL командами (CREATE, ALTER, DROP)
