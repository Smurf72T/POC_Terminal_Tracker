## Шаг 1: QWidget → QDialog в .ui файлах

**Файлы (10 шт., все в `src/ui/dialogs/`):**

- `archivedocumentsform.ui`
- `clientsform.ui`
- `manufacturersform.ui`
- `modelsform.ui`
- `paymentform.ui`
- `receiptform.ui`
- `rentalform.ui`
- `returnform.ui`
- `simcardsform.ui`
- `terminalsform.ui`

**Действие:**
В каждом файле заменить первую строку:
```xml
<class>QWidget</class>
```
на:
```xml
<class>QDialog</class>
```

Этого достаточно — Qt Designer автоматически обновит базовый класс виджета. C++ классы уже наследуют QDialog.

## Шаг 2: Уникальные objectName для лейблов дашборда

**Файл:** `src/ui/mainwindow.ui`

**Сейчас:**
- 6 лейблов с `objectName="counterValue"` (разные name: `labelValueTotal`, `labelValueFree` и т.д.)
- 6 лейблов с `objectName="counterName"` (разные name: `labelNameTotal`, `labelNameFree` и т.д.)

**Замена (objectName → уникальные):**

| Текущий objectName | Новый objectName |
|---|---|
| counterValue (labelValueTotal) | labelTotalValue |
| counterValue (labelValueFree) | labelFreeValue |
| counterValue (labelValueRented) | labelRentedValue |
| counterValue (labelValueTotalSIM) | labelSimTotalValue |
| counterValue (labelValueFreeSIM) | labelSimFreeValue |
| counterValue (labelValueClients) | labelClientsValue |
| counterName (labelNameTotal) | labelTotalName |
| counterName (labelNameFree) | labelFreeName |
| counterName (labelNameRented) | labelRentedName |
| counterName (labelNameTotalSIM) | labelSimTotalName |
| counterName (labelNameFreeSIM) | labelSimFreeName |
| counterName (labelNameClients) | labelClientsName |

**Файл:** `src/ui/mainwindow.cpp`

В `updateCounterWidget()` заменить хрупкий `endsWith` на прямой `objectName ==`:

```cpp
// Было:
for (auto* child : widget->findChildren<QLabel*>()) {
    if (child->objectName().endsWith("Value")) {
        valueLabel = child;
        break;
    }
}

// Стало:
for (auto* child : widget->findChildren<QLabel*>()) {
    if (child->objectName() == "Value" || child->objectName().contains("Value", Qt::CaseInsensitive)) {
        valueLabel = child;
        break;
    }
}
```

ИЛИ лучше — использовать конкретные указатели через `ui->`:
```cpp
QLabel* valueLabel = ui->labelValueTotal; // для frameTotalTerminals
```

Самый чистый вариант — явно обратиться к `ui->` полям вместо `findChildren`.

## Шаг 3: Печать акта до проведения документа

**Файлы:** `src/ui/dialogs/rentalform.cpp`, `src/ui/dialogs/rentalform.h`

**Контекст:**
- `on_btnPrintAct_clicked()` — печатает акт на основе заполненных данных формы, но НЕ требует проведения
- `on_btnPost_clicked()` — проводит документ, фиксирует транзакцию
- Акт можно распечатать в любой момент, даже до проведения

**Решение:** Добавить предупреждение (QMessageBox::warning) при печати незапроведённого документа.

**Файл: `src/ui/dialogs/rentalform.h`**
Добавить приватное поле:
```cpp
bool isPosted = false;
```

**Файл: `src/ui/dialogs/rentalform.cpp`**

В `on_btnPrintAct_clicked()` — в самом начале, после проверки клиента:
```cpp
void RentalForm::on_btnPrintAct_clicked()
{
    int clientId = ui->comboBoxClient->currentData().toInt();
    if (clientId == 0) {
        QMessageBox::warning(this, "Внимание", "Сначала выберите клиента!");
        return;
    }

    // ПРЕДУПРЕЖДЕНИЕ: документ не проведён
    if (!isPosted) {
        int btn = QMessageBox::warning(this, "Внимание",
            "Акт будет распечатан до проведения документа. "
            "После проведения данные могут измениться.\n\n"
            "Распечатать как черновик?");
        if (btn != QMessageBox::Yes) return;
    }

    // ... остаток логики печати без изменений
}
```

В `on_btnPost_clicked()` — после успешного commit:
```cpp
if (!db.commit()) {
    db.rollback();
    QMessageBox::critical(this, "Ошибка", "Не удалось зафиксировать транзакцию");
} else {
    isPosted = true;  // <-- добавить
    QMessageBox::information(this, "Успех", "Документ успешно проведен!");
    DatabaseManager::instance().notifyDataChanged();
    this->close();
}
```

## Шаг 4: ComboBoxDelegate "0" как текст → setData(0, Qt::UserRole)

**Файл:** `src/ui/dialogs/receiptform.cpp`

**Метод:** `on_btnAddRow_clicked()`

**Сейчас (строка ~установка model column):**
```cpp
rowsModel->setItem(row, 1, new QStandardItem("0"));
```

**Стало:**
```cpp
QStandardItem* item = new QStandardItem();
item->setText("0");
item->setData(0, Qt::UserRole);  // ID модели как int в UserRole
rowsModel->setItem(row, 1, item);
```

Также нужно убедиться, что при чтении данных в `on_btnPost_clicked()` используется согласованное чтение:
```cpp
// Читать:
int modelId = rowsModel->data(rowsModel->index(i, 1), Qt::UserRole).toInt();
```
