# sql/legacy — архивные SQL-скрипты

Скрипты в этой папке **заменены миграциями** (`sql/migrations/`) и больше
не должны применяться вручную. Они сохранены для истории и справки.

| Файл | Заменён миграцией | Примечание |
|------|-------------------|------------|
| `audit_log.sql` | `001_initial.sql` | `tbl_users`, `tbl_audit_log`, триггеры аудита, дефолтный `admin` |
| `doc_sequences.sql` | `002_status_change_docs.sql`, `003_doc_number_sequences.sql` | `generate_doc_number` (формат `ПП-00001`) и последовательности |
| `add_indexes.sql` | `000_base_schema.sql` | Все 25 индексов и ограничения |

> Все объекты создаются автоматически при первом запуске приложения (миграции
> применяются раннером под `pg_advisory_lock`). Применение этих скриптов вручную
> может привести к рассинхронизации схемы с `schema_migrations`.
