# Changelog

## [1.2.0] — 2026-07-31

### Data integrity
- **Нумерация документов на чистой БД**: миграция `003_doc_number_sequences.sql` — последовательности для поступлений, аренд, возвратов, оплат и изменений статусов
- **Транзакционные миграции**: запись версии в `schema_migrations` выполняется в одной транзакции с SQL-миграцией

### Backup & Restore
- **Бэкап без хардкода localhost**: host/port/db/user берутся из текущего подключения
- **Восстановимые дампы**: pg_dump с `--clean --if-exists`, restore в `--single-transaction`, любые ошибки теперь видны (NOTICE/WARNING больше не игнорируются)
- **Полный fallback-дамп**: последовательности (с setval), DEFAULT-значения, функции, триггеры, неконстрейнтные индексы, ограничения (FK в конце)

### Security
- **Constant-time проверка пароля**: сравнение хэшей PBKDF2/SHA-256 без раннего выхода по несовпадению
- **Аудит с реальным пользователем**: `set_config('app.username', …)` после входа — записи аудита больше не помечаются как «system»

### Fixes
- **HTML-экранирование** пользовательских полей в печатных формах и архивах
- **Массовый импорт импортирует весь файл**, а не первые 50 строк предпросмотра; корректные номера строк в ошибках
- **Журнал импорта**: пользователь из сессии вместо хардкода `admin`
- **Тема сохраняется** в QSettings и применяется после входа

### Housekeeping
- Удалён неиспользуемый `tests/CMakeLists.txt` (таргеты тестов — в корневом CMakeLists)

## [1.1.0] — 2026-07-31

### Features
- **Документы изменения статуса терминалов**: в ремонт, возврат из ремонта (на основании документа «в ремонт»), списание, утеря
- **Флаг «ремонтировался»** (`was_repaired`) в карточке терминала — устанавливается при передаче в ремонт, отображается в справочнике терминалов
- **Комментарий обязателен**: причина списания/утери или состав ремонта фиксируется в документе
- **Печать актов**: передача в ремонт, возврат из ремонта, списание, утери
- **Архив «Изменение статусов»** с фильтром по периоду и экспортом в Excel/PDF
- **Нумерация документов**: генератор `generate_doc_number` расширен типом `statuschange` (префикс «ИС-»)
- **Миграция `002_status_change_docs.sql`**: таблицы `tblstatuschangedocs`/`tblstatuschangedetails`, колонка `was_repaired`, индексы

## [1.0.0] — 2026-07-30

### Security
- **SQL-инъекции устранены**: все LIKE-фильтры переписаны через `QSqlField::formatValue()` (clientsform, modelsform, simcardsform, manufacturersform)
- **PBKDF2-HMAC-SHA256** с 100k итераций для хранения паролей вместо SHA-256+salt; авто-апгрейд при логине
- **Rate limiting**: блокировка входа на 30 сек после 5 неудачных попыток
- **SSL принудительно**: удалён fallback на unprotected-соединение с PostgreSQL
- **Больше никаких паролей на диске**: бекап через `PGPASSWORD` (env var), `.env` исключён из сборки

### Features
- **Система миграций БД**: авто-применение `sql/migrations/*.sql` при запуске
- **Ролевая защита UI**: скрытие admin-меню для обычных пользователей
- **Принудительная смена пароля** при первом входе
- **QLoggingCategory**: логи через `logDB`, `logAudit`, `logMigration`, `logSQL`, `logApp` вместо `qDebug()`

### Performance & Stability
- **Database indexes**: 25 индексов + CHECK-ограничения + UNIQUE на serialnumber
- **Утечка памяти в графиках**: оси удаляются перед обновлением `updateCharts()`
- **Проверка `query.exec()`**: 11 вызовов обёрнуты в `if (!exec()) { qDebug() << error; }`

### Quality
- **Unit-тесты**: `test_password_utils` (6 тестов для PBKDF2, обратная совместимость), `test_validator` (15 тестов для IMEI, INN, Luhn, серийных номеров)
- **CMake**: смягчена версия Qt до 6.2, проверка наличия DLL-путей, опция `BUILD_TESTS`

### Bugfixes
- **`QMessageBox::critical(nullptr,...)`**: заменён на parent-окно или `QApplication::activeWindow()`
- **Беказ без `.pgpass`**: пароль через PGPASSWORD вместо временного файла
- **Мусор из индекса удалён**: `stderr.txt`, `stdout.txt`, `test_result.txt`
