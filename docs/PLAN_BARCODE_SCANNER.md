# План: сканер штрих-кода в «Поступлении терминалов»

> (USB keyboard-wedge, 2D-сканер для IMEI в QR/DataMatrix).
> Не влияет на валидацию при проведении: она остаётся в `on_btnPost_clicked`.

## Шаг 2. `BarcodeParser` + тесты

**Файлы:**
- `src/utils/barcodeparser.h`
- `src/utils/barcodeparser.cpp`
- `tests/test_barcodeparser.cpp`

**Что делает:** чистый парсер «сырой» строки сканера в поля `SN/IMEI1/IMEI2`
(без GUI и без работы с событиями — легко тестировать):

1. **Простой SN** (`ABC-12345`) → `serial`.
2. **Голые 15 цифр** → `imei1` (правило: ровно 15 цифр = IMEI).
3. **Подписанный payload** (`SN:ABC-123 IMEI1:356… IMEI2:356…`, разделители
   пробел/`,`/`\n`/`\t`) → разложить по полям.
4. **GS1/ASCII-разделители** (`\x1D`, `\x1E`, `\x04`) → нормализуются в пробелы.
5. Общий `IMEI:…` (без номера слота) → в первую свободную колонку IMEI.

**Критерии готовности:** `test_barcodeparser` проходит (QTest, без GUI).

**Статус:** ✅ ВЫПОЛНЕНО (14.08.2026). Добавлены `BarcodeParser` (форматы 1–5,
включая GS1-разделители \x1D/\x1E/\x04) и `test_barcodeparser` (10 кейсов,
все зелёные).

**Трудозатраты:** ~1–2 ч. Риск: низкий.

## Шаг 3. `BarcodeScanner` + тесты

**Файлы:**
- `src/utils/barcodescanner.h`
- `src/utils/barcodescanner.cpp`
- `tests/test_barcodescanner.cpp`

**Что делает:** детектор клавиатурного сканера (keyboard wedge).

- Накапливает печатный ASCII-ввод в буфер; скан «завершён», когда пауза между
  символами > `interCharTimeoutMs` (50 мс по умолчанию) или пришёл терминатор
  (Enter/Tab).
- Буфер короче `minLength` (3) не выдаётся как скан (защита от случайных нажатий).
- Сигналы: `scanStarted`, `scanFinished(raw)`.
- Не зависит от GUI (только `QTimer`) — тестируется синтетическими `feed()`.

**Критерии готовности:** `test_barcodescanner` проходит (feed + терминатор +
таймаут + minLength).

**Статус:** ✅ ВЫПОЛНЕНО (14.08.2026). Добавлены `BarcodeScanner` и
`test_barcodescanner` (5 кейсов: терминатор, minLength, коммит по таймауту,
пустой терминатор, игнор пробелов; все зелёные). Шаги 2 и 3 закоммичены
вместе, т.к. их CMake-таргеты связаны.

**Трудозатраты:** ~1–2 ч. Риск: низкий.

## Шаг 4. Интеграция в `ReceiptForm` + сборка

**Файлы:**
- `src/ui/dialogs/receiptform.{h,cpp}`
- `CMakeLists.txt`

**Что делает:**
- `qApp->installEventFilter(this)` в конструкторе (снять в деструкторе).
- Перехват печатных клавиш: если форма активна и фокус **не** в текстовом
  редакторе (`QLineEdit`/`QTextEdit`/`QPlainTextEdit`/`QComboBox` и редактор
  ячейки таблицы) — символы уходят в `BarcodeScanner` и поглощаются.
  Терминатор Enter/Tab завершает скан и тоже поглощается (не нажимает кнопку
  по умолчанию, не уводит фокус).
- `onScanFinished(raw)` → `BarcodeParser::parse(raw)` → вставка:
  - если у текущей строки таблицы ещё нет SN — заполняем её;
  - иначе создаём новую строку (быстрое сканирование пачки устройств);
  - SN → колонка 0, IMEI 1 → колонка 2, IMEI 2 → колонка 3;
  - колонка «Модель» остаётся ручным выбором (дефолт — первая из справочника);
  - после вставки фокус возвращается на таблицу (для серии сканов).
- Регистрация новых файлов и тестов в `CMakeLists.txt`.

**Критерии готовности:** проект собирается, `test_barcodeparser` и
`test_barcodescanner` зелёные, ручная проверка: скан пачки устройств.

**Статус:** ⏳ в работе.

**Трудозатраты:** ~1–2 ч. Риск: средний (поведение фокуса, поглощение клавиш).

## Ограничения MVP

- Только keyboard-wedge сканеры (USB). COM/TCP — отдельный этап (нужен `QSerialPort`).
- Скан обрабатывается, когда фокус не в текстовом поле: оператор сканирует,
  держа фокус на таблице (после каждого скана фокус возвращается на таблицу).
- Нужен 2D-сканер для IMEI в QR/DataMatrix; голые 15 цифр считаются IMEI.
- «Модель» не заполняется сканом (остаётся ручной выбор).
